如何启动

方式一：一键容器（推荐，自动建中文表 + 写演示数据）

docker compose up -d --build
前端 http://localhost:8080，接口 http://localhost:3000/api/v1

方式二：本地开发

npm install --no-audit --no-fund --ignore-scripts → 配置 .env → npx prisma migrate dev && npx prisma db seed → 分别 npm run dev:server / npm run dev:web
