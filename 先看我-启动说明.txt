 AI Demo Hub · 接线机器人 + 电销工作台 —— 本地启动
============================================================

【首选：免 Docker，只装 Node（推荐）】
 1) 安装 Node.js 20 LTS 或更高（普通安装包，一路下一步，不需要 Docker、
    不需要单独装数据库）：https://nodejs.org/zh-cn/download
 2) 解压本压缩包，进入 ai-demo-hub-platform 文件夹：
    · Windows 双击「启动-免Docker版.bat」
    · macOS   双击「启动-免Docker版.command」（首次被拦截就右键→打开）
 3) 首次会自动装依赖、构建、启动内置数据库和前后端（约 5-10 分钟），
    之后启动约 30 秒；完成后自动打开浏览器。
    访问 http://localhost:8080  账号 admin  密码 Aihub@123456
 4) 想恢复初始演示数据：双击「重置演示数据-免Docker版」后重新启动。
 说明：内置 PostgreSQL 数据放在 .local-pgdata，缓存走进程内存，
      全程离线可跑，无需任何外部 AI/语音密钥（内置沙箱模型）。

【备选：用 Docker（已装 Docker Desktop 时）】
 Windows 双击「启动-Demo.bat」/ macOS 双击「启动-Demo.command」，
 完成后访问 http://localhost:8080，停止用「停止-Demo」。

【其它账号】manager / agent01 / agent02，密码同为 Aihub@123456
【遇到问题】把启动窗口的报错截图发来即可；详细说明见「本地启动指南.md」
